01 What it is

Bourse is a small stock exchange and a robot that trades on it. Tests check both, so nobody has to trust them. The exchange matches buyers and sellers first by price and then by arrival time. It never loses an order. It gives the same answer every time it gets the same orders.

The robot tries to earn the gap between the buy price and the sell price. Strict tests judge the robot. They treat every profit as luck or a cheat until the robot proves otherwise.
